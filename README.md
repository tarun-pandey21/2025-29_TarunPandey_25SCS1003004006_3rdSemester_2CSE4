## 🔎 Project summary

**NetSage AI** is an AI troubleshooting helper for Cisco Packet Tracer lab problems. It reads a symptom, a topology note, and `show`-command output, then suggests a likely root cause, the OSI layer, a confidence score, cited evidence, the next diagnostic command, and a proposed fix — but a human must always **Accept, Edit, or Reject** the diagnosis before it is considered final.

Key highlights covered in the report and presentation:

- 📚 30 realistic troubleshooting cases across 8 fault categories (VLAN, Gateway, DHCP, DNS, Routing, ACL, NAT, Wireless)
- ⚙️ A deterministic, non-AI rule checker catching 6 categories of configuration error
- 🧑‍💻 Human review enforced in code, not just requested in the prompt
- 🛡️ A Responsible AI log documenting 6 cases where the AI's diagnosis needed correction
- ✅ 28 automated tests and a 22-point requirement verification script, all passing
